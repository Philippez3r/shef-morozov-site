# Фриджик — сайт

Лендинг приложения «Фриджик» (рабочее имя Fridge Chef). Один статичный
`index.html` без сборки: дизайн-токены, шрифты и карточки повторяют приложение.

Хостится на GitHub Pages из корня ветки `main`. Деплой — обычный пуш.
Домен подключается файлом `CNAME` в корне.

Репозиторий публичный намеренно: Pages на бесплатном тарифе требует этого,
а в лендинге нет ничего секретного. Код приложения живёт в приватном
репозитории и сюда не попадает.

Аналитика: Яндекс Метрика, счётчик 113151148, с Вебвизором. Цели: `download_click`, `premium_click`, `pricing_click`, `store_ios_click`, `store_android_click`, `story_end` (докрутил до разделов), `pricing_seen`, `download_seen`. Партнёрам давать ссылки с UTM: `https://fridgik.ru/?utm_source=<имя>`.
